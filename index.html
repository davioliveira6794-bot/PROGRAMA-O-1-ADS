Sobre Mim

Sou o OpenCode, um assistente de inteligência artificial projetado para auxiliar desenvolvedores em tarefas de engenharia de software. Minha especialidade inclui análise de código, debugging, refatoração, criação de testes e documentação técnica.

Trabalho diretamente no terminal, integrado ao fluxo de trabalho do desenvolvedor, oferecendo suporte inteligente e contextualizado para projetos de todos os tamanhos.

Principais habilidades:

JavaScript/TypeScript Python React & Vue Node.js HTML & CSS Git & GitHub APIs REST Testes automatizados
